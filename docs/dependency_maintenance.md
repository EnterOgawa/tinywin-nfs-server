# 依存関係の管理

取得元・版・SHA-256・対応ソースは `dependencies/components.json` を単一の一覧として管理します。実際に採用した runtime と jar の情報は app image の `build-information.json` に記録します。

| コンポーネント | 現在の指定 | 通常確認 | 更新時の確認 |
|---|---|---|---|
| Java | ビルドは Java 21、配布は Temurin 21.0.11+10 Windows x64 | 版を JDK の `release` から確認 | ベンダーの更新情報、対応ソース、単体・通信・実クライアントの回帰 |
| SWT | 3.129.0 Windows x86_64 | jar の SHA-256 を確認 | GUI、文字表示、アイコン、Java/native ソースとライセンス |
| WinSW | 2.12.0 NET461 版 | exe の SHA-256 を確認 | .NET Framework 4.8 以降、インストール、停止、再起動、更新、内包ライブラリの通知と対応ソース |
| CI actions | workflow 内の完全なコミット SHA に固定 | PR で確認 | 上流リリースと permissions の変更 |

## 更新方針

- 少なくともリリース前に、ベンダーの更新とセキュリティ情報を確認します。
- 版だけを変更せず、公式配布元から取得したファイル、期待ハッシュ、対応ソース、ビルド情報をまとめて更新します。
- 取得後にハッシュを表示するだけではなく、指定した期待値に一致しないファイルの採用を拒否します。
- Java の更新では NFS のキャッシュ、時刻、属性、サービス停止・再起動を含む回帰を確認します。
- 配布 JDK のパッチ版と対応ソースが一致しない場合はパッケージを作成しません。
- Dependabot だけでは直接取得する jar・exe・runtime の全てを管理できないため、この一覧もレビューします。

新しいハッシュを採用する際は、公式の配布情報・署名・ハッシュと照合し、変更理由を PR に記載してください。
更新の採用後も、メンテナーの動作確認・手動署名・明示的な公開指示を経てリリースします。

## WinSW の runtime

以前の `WinSW-x64.exe` は .NET 6.0.13 を内包します。.NET 6 は 2024-11-12 にサポートを終了しているため、次の配布では同じ WinSW 2.12.0 の `NET461` 版を使用し、OS 側の .NET Framework 4.8 以降に更新を委ねます。
インストーラーは .NET Framework の前提を確認してから処理を開始します。既存の署名済み配布物やインストール済みサービスは、このソース変更で置換されません。サービス導入・停止・再起動の実環境確認はリリース前に必要です。
[Microsoft の .NET サポート方針](https://dotnet.microsoft.com/en-us/platform/support/policy/dotnet-core)
